# Cat example 2026

Don't be too excited. This is just a project repository to bind together Hilt and Navigation2 + Navigation-Compose while using Gradle Version Catalogs and build.gradle.kts.

Interestingly, finding what you need to put in to the version catalogs and your build.gradle.kts files is not as simple as you'd assume the Google recommendations to be.
